E-Portfolio

This site itself is a personal project. I built it from scratch to document my coursework and extracurriculars in a format I control, rather than relying on a template builder. It's hand-written HTML styled with Tailwind CSS and hosted for free on GitHub Pages, which let me practice basic version control alongside the design work.

Goals

  • Build a portfolio that reflects an engineering mindset, not just a generic resume site
  • Learn the basics of HTML, CSS, and Git/GitHub in the process
  • Keep the site easy to update as new projects come in
